# StreamFlix

A lightweight Netflix-style movie app built with plain HTML, CSS, and JavaScript.

Features:
- Netflix-inspired dark UI
- Hero banner section
- Movie row cards with search filter
- Modal player for previewing selected movie clips
- Responsive layout for desktop and mobile
- Uses public-domain and open-source movie samples for demo playback

How to run:
1. Open `index.html` directly in a browser, or
2. Serve the project locally with a simple web server:

```bash
python3 -m http.server 8000
```

Then visit:
- http://localhost:8000

Files included:
- `index.html` — main UI structure
- `styles.css` — styling and layout
- `app.js` — movie data and interactions

Note:
This project is a demo/front-end app inspired by Netflix, not a licensed streaming platform.
It is designed for learning and local demonstration purposes.
